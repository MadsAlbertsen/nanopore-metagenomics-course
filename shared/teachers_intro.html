Course material

For teachers

Each module works for a session of 45-60 minutes: a short introduction by the teacher, then students work through the guided examples in pairs, and the session ends with the take-home points and the discussion question. The times below are estimates; they have not been tried with students yet.

Practical points. The pages run in any recent browser on a laptop; the binning maps need a mouse or trackpad for selecting. Every view can be shared as a link: set the page up, use "Copy link to this view" (in Assembly, copy the address from the browser bar), and paste the link into slides or the course platform. A link ending in #?ex=3 opens example 3 with its setup. For offline use, or a version that cannot change during the course, use the zip on the front page, or publish a GitHub release (the zip is attached to it). Students can report problems from the link at the bottom of every page.

The answers to the guided examples are on the pages (hidden until opened), so the discussion points below are the only extra material. Every number in the examples comes from the analysis (in module 3, from the simulations) and was checked again by an independent review.
